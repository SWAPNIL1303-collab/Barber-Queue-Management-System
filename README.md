# Barber Q: Smart Digital Queue Management System

Barber Q is a smart digital queue and salon management system designed to modernize the traditional barber-shop experience. It allows customers to find nearby barbers, explore available services, join a digital queue, view their live token status, and reduce unnecessary waiting time.

For barbers and shop owners, the system provides a centralized dashboard to manage customers, services, tokens, and the live queue efficiently.

## Key Features
🔎 Find nearby barber shops
💈 Browse available services
🎟️ Generate and manage digital tokens
📊 View the live queue and current token
👤 Track your own token status
⏱️ Reduce physical waiting time
🧑‍💼 Barber/shop-owner management dashboard
📱 Simple and user-friendly interface
🔄 Real-time queue updates
Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
Database: MySQL

## Objective

The main objective of Barber Q is to replace traditional physical queues with a smart digital queue-management system, making the barber-shop experience faster, more convenient, and organized for both customers and shop owners.
